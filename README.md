
# AJAX-CES2027
Заявка на поїздку CES 2027.

[Курсова робота](Курсоваробота) - курсова робота, де описане дослідження мікроконтролерів.

[Мотиваційний лист](Мотиваційнийлист) - мотиваційний лист до заявки.

[Сертифікати](Сертифікати) - сертифікати, які підтверджують участь у CTF-змаганнях, проходження курсів та рівень англійської мови.
